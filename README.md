# MIND FORGE

تطبيق Android-friendly / PWA باللغة العربية لتدريب مهارات معرفية محددة وقياس الأداء داخل التمارين.

## الإصدار 0.2
- لوحة رئيسية عربية RTL بتصميم متجاوب.
- 3 تدريبات: استرجاع الأرقام، تداخل الألوان (Stroop-style)، واكتشاف الأنماط.
- جلسات متعددة الجولات مع تغذية راجعة ونتيجة لكل جلسة.
- أفضل نتيجة منفصلة لكل مهارة، وسجل آخر 8 جلسات.
- خطة يومية مقترحة بثلاث مهارات ومؤشر إنجاز.
- حفظ محلي عبر LocalStorage، دون حساب أو API أو إرسال بيانات.
- PWA وService Worker للتخزين المؤقت بعد أول تحميل.

## النشر على GitHub Pages
1. Settings → Pages.
2. اختر Deploy from a branch ثم main و /(root).
3. افتح رابط Pages على Chrome في Android.
4. من قائمة Chrome اختر Install app أو Add to Home screen.
5. افتح التطبيق مرة مع الإنترنت حتى تُخزّن الملفات، ثم اختبره دون اتصال.

## الخصوصية
البيانات محفوظة في تخزين المتصفح المحلي على الجهاز. حذف بيانات الموقع/المتصفح قد يمسح السجل. لا تُرسل النسخة الحالية بيانات إلى خادم.

## الدقة العلمية
الدرجات تقيس الأداء في المهام الموجودة داخل التطبيق فقط، وليست اختبار ذكاء معياريًا أو تشخيصًا طبيًا. لا يجوز تفسير التحسن في اللعبة على أنه تحسن مثبت في الذكاء العام أو في أداء البرمجة واللغات. الإصدارات التالية ستضيف تقييمًا مبدئيًا أكثر اتزانًا، مهامًا تطبيقية، وقياسًا عبر الزمن.

## خارطة الطريق
1. اختبارات baseline وإعادة تقييم دورية لكل مهارة.
2. مستويات صعوبة متدرجة وموازنة الأسئلة والتوقيت.
3. رسوم تقدم ومقارنة الأداء عبر جلسات متعددة.
4. أوضاع تطبيقية للبرمجة وتعلم اللغات وحل المشكلات.
5. إعداد Android APK عبر GitHub Actions واختباره على أجهزة حقيقية.
