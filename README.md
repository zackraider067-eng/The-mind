# MIND FORGE

تطبيق عربي لتدريب مهارات معرفية محددة وقياس الأداء داخل التمارين.

## الإصدار 0.1 — أول نسخة قابلة للتجربة
- واجهة عربية RTL متجاوبة مع الهاتف.
- تمرين ذاكرة الأرقام: عرض تسلسل ثم استرجاعه.
- تمرين تركيز الألوان: الانتباه للون الحبر بدل معنى الكلمة.
- تمرين المنطق والأنماط: إكمال متتاليات رقمية.
- حفظ الجلسات وأفضل نتيجة وأيام التدريب محليًا عبر LocalStorage.
- PWA وService Worker للتشغيل دون اتصال بعد أول تحميل ناجح.
- لا حسابات ولا مفاتيح API ولا إرسال لبيانات المستخدم.

## تشغيله على Android
1. فعّل GitHub Pages للمستودع من Settings → Pages.
2. اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واحفظ.
3. افتح رابط GitHub Pages في Chrome على Android.
4. من قائمة Chrome اختر Install app أو Add to Home screen.
5. افتح التطبيق مرة مع الإنترنت حتى يتم تخزين الملفات، ثم جرّب وضع الطيران.

## تنبيه علمي
النتائج الحالية تقيس أداء المستخدم في هذه التمارين فقط. ليست اختبار ذكاء معياريًا أو تشخيصًا طبيًا، ولا تثبت وحدها تحسن الذكاء العام أو انتقال التحسن إلى كل مجالات الحياة. سنطوّر القياس تدريجيًا ونفصل بين أداء التدريب والمهارات الواقعية.

## خارطة الطريق
1. تحسين جودة التمارين وتنوعها والتحقق من الإجابات والتوقيت.
2. اختبار مبدئي (Baseline) لكل مهارة وخطة تدريب شخصية.
3. سجل أداء ورسوم تقدم أسبوعية مع مقارنة عادلة.
4. أوضاع تطبيقية للبرمجة وتعلم اللغات وحل المشكلات.
5. إعداد بناء APK عبر GitHub Actions، ثم اختبار التثبيت على أجهزة Android.

## الخصوصية
الإصدار الحالي يحفظ إحصاءات التدريب محليًا على الجهاز فقط. مسح بيانات المتصفح قد يحذف تقدمك.
