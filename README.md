# MIND FORGE

منصة عربية مبنية بمبدأ **Offline-First**: الوظائف الأساسية والتمارين والنتائج تعمل محليًا على الجهاز بعد أول تحميل ناجح.

## الإصدار 0.3 — أساس العمل دون إنترنت
- كل التدريبات الحالية تعمل داخل المتصفح دون طلبات إلى خادم.
- حفظ سجل الجلسات وأفضل النتائج محليًا عبر LocalStorage.
- مؤشر اتصال يوضح حالة الاتصال الحالية.
- Service Worker يخزّن ملفات التطبيق الأساسية ويعرض الصفحة المحفوظة عند انقطاع الإنترنت.
- لا يوجد تسجيل دخول أو API أو إرسال لنتائج المستخدم.
- تحديث رقم نسخة التخزين المؤقت لضمان تحميل ملفات الإصدار الجديد.

## ما الذي يعنيه «أوفلاين» هنا؟
1. افتح رابط التطبيق مرة واحدة مع اتصال إنترنت حتى يكتمل تحميل الصفحة وتثبيت Service Worker.
2. افتحه مرة أخرى بعد ذلك، ثم جرّب وضع الطيران.
3. يجب أن تعمل التدريبات والنتائج المحفوظة على نفس المتصفح والجهاز.
4. مسح بيانات المتصفح أو بيانات الموقع قد يحذف النتائج المحلية والملفات المخزنة.
5. لا يمكن للتطبيق جلب مكتبات أو دروس لم يتم تضمينها أو تنزيلها مسبقًا.

**تنبيه:** لم يتم حتى الآن إجراء اختبار فعلي على جهاز Android أو التحقق من سلوك GitHub Pages بعد النشر. يلزم اختبار ذلك قبل اعتبار دعم الأوفلاين معتمدًا نهائيًا.

## النشر على GitHub Pages
1. افتح Settings → Pages.
2. اختر Deploy from a branch ثم الفرع main والمجلد /(root).
3. افتح رابط Pages على Chrome في Android.
4. من قائمة Chrome اختر Install app أو Add to Home screen.
5. اترك الصفحة مفتوحة حتى يكتمل التحميل، ثم اختبرها دون اتصال.

## الخصوصية والدقة العلمية
- البيانات محفوظة محليًا في المتصفح ولا تُرسل إلى خادم في النسخة الحالية.
- حذف بيانات الموقع/المتصفح قد يمسح سجل التدريب.
- الدرجات تقيس الأداء في التمارين الموجودة فقط، وليست اختبار ذكاء معياريًا أو تشخيصًا طبيًا.
- التحسن في لعبة لا يثبت وحده تحسن الذكاء العام أو انتقال التحسن إلى البرمجة واللغات.

## خارطة الطريق
1. اختبارات تحديد مستوى (Baseline) مستقلة لكل مهارة.
2. مستويات صعوبة متدرجة وتكيّف محسوب حسب أداء المستخدم.
3. سجل تقدم ورسوم بيانية ومراجعات دورية.
4. مكتبات تعلم قابلة للتنزيل: لغات، برمجة، علوم ومهارات عملية.
5. إعداد APK واختباره على أجهزة Android حقيقية.

## بنية التوسع
سيظل التطبيق الأساسي صغيرًا، وتُضاف المواد التعليمية لاحقًا كمكتبات اختيارية قابلة للتنزيل. الهدف ألا يضطر المستخدم إلى تنزيل عدة جيجابايت عند تثبيت التطبيق لأول مرة.
